# Abhishek P | AI/ML Engineer & Full Stack Developer Portfolio

A modern, high-performance developer portfolio featuring cyber-dark aesthetics, an interactive preloader gate with matrix deciphering, an interactive skill particle network (Agent Graph Canvas), and a live performance dashboard.

## 🚀 Live Features

- **Cyber Preloader & Cipher Intro**: Interactive welcome gate with Web Audio API synthesizer, matrix letter decoding into `ABHISHEK P`, 3D tilted cyber grid, and animated scanner beam.
- **Agent Graph Canvas**: Physics-based interactive particle network connecting skill nodes dynamically on proximity and mouse attraction.
- **Verified Performance Dashboard**: Real-time counter metrics for model accuracy (96.86%), academic CGPA (8.2/10), and certifications.
- **Live Spam Detection Simulator**: Interactive client-side Naive Bayes & TF-IDF message classifier modal.
- **AI Agent Assistant ("ASK ABHI AGENT")**: Interactive assistant drawer simulating thought streams and answering questions about skills, projects, and contact info.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices with glassmorphism design.

## 💻 How to Run Locally

Simply clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/ABHISHEKp231/protfolio.git
cd protfolio
```

Or run with Python's built-in web server:

```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.
